# NETCONF 脚本运行流程文档

## 概述

本文档描述 `run_scripts.py` 中脚本运行和修复的完整流程。

---

## 核心逻辑说明

**修复策略**：
- **无总次数限制**：可以无限循环修复
- **按函数限制**：每个函数最多修复3次
- **自动切换**：如果修复的是不同函数，重置计数器继续修复

**退出条件**：
1. 运行成功（`total_failures == 0`）
2. 连续3次修复同一函数仍然失败 → **停止整个工作流**
3. 修复函数本身失败

## 详细步骤说明

### 步骤1: 记录开始时间
- 使用 `time.time()` 记录脚本运行前的时间戳
- 用于后续筛选新生成的 pytestlog.json 文件

### 步骤2: 查找测试脚本
- 在子文件夹中查找 `test_netconf*.py` 文件
- 如果找到，使用该文件；如果未找到，运行所有 `test_*.py` 文件

### 步骤3: 构造请求
- 创建 `RunSingleScriptRequest` 对象
- 传入脚本路径（可能为空，表示运行所有脚本）

### 步骤4: 调用运行接口
- 调用 `itc_router.run_script(request)` 启动脚本运行
- 保存 response 到 `response.json` 文件（用于调试）

### 步骤5: 等待 pytestlog.json 文件
- 调用 `wait_for_pytestlog_json(log_dir, start_time)` 等待文件生成
- **最多等待 6 分钟**
- **筛选条件**：
  - 文件名以 `test` 开头
  - 文件修改时间 > `start_time`
  - 如果有多个新文件，选择最新的

### 步骤6: 解析并判断成功
- 调用 `parse_script_return_info()` 解析 pytestlog.json
- 提取 `error_summary.total_failures`
- **判断标准**：
  - `total_failures == 0`：运行成功 ✓
  - `total_failures > 0`：运行失败，进入修复流程

### 步骤7: 调用修复函数
- **第一次失败时**：保存原始的 `return_info`（json 字符串）到 `first_error_summary`
- **每次都传入第一次的 `return_info`**
- 调用 `_fix_scripts_for_subdir(subdir, first_error_summary)`
- 修复函数内部会解析 `return_info` 并调用 Claude Agent

### 步骤8: 检查修复结果
- 如果修复失败，直接返回
- 如果修复成功，记录修复的函数名

### 步骤9: 检查函数名（按函数限制修复次数）
- 记录连续修复同一函数的次数
- **每个函数最多修复 3 次**
- 如果是不同函数：重置计数器为 1，继续修复
- 如果连续 3 次修复同一函数：退出循环（该函数无法修复）

### 步骤10: 继续下一次循环
- 回到步骤 1，重新运行脚本
- 无限循环，直到满足退出条件

---

## 关键要点

### 1. 退出条件
- **运行成功**：`total_failures == 0`
- **同一函数修复3次失败**：`same_function_count >= 3` → **停止整个工作流，不再处理其他子文件夹**
- **修复函数本身失败**：`fixed_scripts == False`

### 2. 判断成功的标准
**不依赖 `response.status`**，而是通过解析 pytestlog.json 文件：
- `total_failures == 0`：成功
- `total_failures > 0`：失败

### 3. 修复逻辑
- 总是传入**第一次**的 `return_info`（json 字符串）
- `_fix_scripts_for_subdir` 内部负责解析

### 4. 按函数限制修复次数
- **无总次数限制**：可以无限循环
- **每个函数最多修复 3 次**
- 如果是不同函数，重置计数器，继续修复

### 5. 文件筛选条件
pytestlog.json 文件必须满足：
- 文件名以 `test` 开头
- 在 `start_time` 之后生成
- 如果有多个，选择最新的

## 返回值

```python
{
    "status": "ok" | "error",
    "message": "描述信息",
    "data": {...}
}
```

- `status == "ok"`：运行成功
- `status == "error"`：运行失败

## 相关函数

| 函数 | 作用 |
|------|------|
| `run_netconf_scripts()` | 入口函数，运行所有或指定子文件夹的脚本 |
| `_run_scripts_for_subdir()` | 核心函数，运行单个子文件夹的脚本（含修复逻辑） |
| `wait_for_pytestlog_json()` | 等待并获取最新的 pytestlog.json 文件 |
| `parse_script_return_info()` | 解析 pytestlog.json 文件内容 |
| `_fix_scripts_for_subdir()` | 修复失败的测试脚本 |
